# discovery

Система мониторинга сетевых устройств для интернет-провайдеров: обнаруживает
коммутаторы, OLT и другое сетевое оборудование в вашей сети, опрашивает их метрики по
SNMP, поднимает тревоги при отклонениях и авариях и шлёт уведомления в
Telegram/email/webhook — без облака, полностью на вашей инфраструктуре.

Этот репозиторий — открытая документация продукта: установка, возможности,
лицензирование, настройка, диагностика. Сам код закрытый (коммерческий продукт).

## Коротко о продукте

- **Обнаружение устройств** — сканирование подсетей по SNMP, автоматическое создание
  записи устройства при первом ответе.
- **Опрос метрик** — по гибко настраиваемому профилю: любые OID, с любой периодичностью,
  под любую модель оборудования.
- **Тревоги** — пороговые срабатывания на любую метрику, с гистерезисом (не дребезжат на
  границе порога) и историей.
- **Уведомления** — email, Telegram, webhook — гибкая матрица «кого извещать по какой
  тревоге и в какое время».
- **Веб-дашборд** — вся работа через браузер, ничего не нужно устанавливать себе на
  компьютер отдельно.
